# Лабораторна 6.2.1 — Налаштування мережного оточення

Цей приклад показує, як клієнт підключається до `iperf3` сервера за допомогою `subprocess` та парсить вивід інтервалів.

## Вимоги
- Встановлений `iperf3` у системі та доступний у `PATH`.
- Windows PowerShell 5.1 (за замовчуванням під час виконання команд).

## Підняти сервер
На машині, що виступає сервером, запустіть:

```powershell
iperf3 -s
```

За потреби вкажіть порт:

```powershell
iperf3 -s -p 5201
```

## Запустити клієнт
Скрипт: `lab7/iperf_client.py`

Приклад запуску:

```powershell
python c:\Users\Влад\OneDrive\Рабочий стол\gl\lab7\iperf_client.py 192.168.1.10 --port 5201 --duration 10
```

Або виставте IP у змінній `server_ip` всередині файлу і просто:

```powershell
python c:\Users\Влад\OneDrive\Рабочий стол\gl\lab7\iperf_client.py
```

Скрипт виведе лише ті інтервали, де `Transfer > 2` MBytes та `Bitrate > 20` Mbits/sec. Якщо `iperf3` не знайдено, побачите відповідну помилку.
